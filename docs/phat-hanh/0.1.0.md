## 2. Ghi chú phát hành (cho thợ và chủ xưởng)
- Web ghép file in mới tại địa chỉ Render (frontend) gọi máy chủ `https://in.dreamate.me`.
- TIF tự chuẩn bị sẵn sau khi ghép: màn kết quả hiện "Đang chuẩn bị file TIF: x/y tấm sẵn sàng"; các nút tải không bị khoá.
- Lưu ý: file và lần ghép tự xoá sau 48 giờ; máy chủ khởi động lại thì lần ghép đang dở bị mất (thông báo nói rõ).

## 3. Các bước deploy (người quản lý duyệt từng bước; agent làm qua Remote Control nếu được cho phép)
1. **DNS (người quản lý tự làm ở Cloudflare):** bản ghi A `in` → `180.93.136.187`, chế độ "DNS only" (mây xám). Xong khi: `nslookup in.dreamate.me` ra 180.93.136.187.
2. **Máy chủ, chuẩn bị (không đụng n8n):**
   - `git clone https://github.com/hoangtra02092006-ui/xuong-in-minh-tri.git /opt/xuong-in/app` (lần sau: `git -C /opt/xuong-in/app pull`).
   - Chép hồ sơ màu: `/opt/xuong-in/color/USWebCoatedSWOP.icc` (từ máy người quản lý, qua Termius SFTP).
   - `cp /opt/xuong-in/app/deploy/.env.example /opt/xuong-in/app/deploy/.env`, sửa `APP_CORS_ORIGINS` thành địa chỉ Render thật.
   - Xong khi: `ls -l /opt/xuong-in/color/USWebCoatedSWOP.icc` ra 557168 byte.
3. **Máy chủ, chạy container:** `cd /opt/xuong-in/app/deploy && docker compose up -d --build`. Xong khi: `docker ps` có `xuong-in-backend` trạng thái `healthy`, và `curl -s 127.0.0.1:8095/api/v1/health` ra `"status":"UP"`. Kiểm `docker ps` các container n8n vẫn chạy như trước.
4. **nginx:** chép `deploy/nginx/in.dreamate.me.conf` vào `/etc/nginx/sites-available/in.dreamate.me`, symlink sang `sites-enabled`, `nginx -t` (phải "syntax is ok"), rồi `systemctl reload nginx` (reload, không restart). Sau đó `certbot --nginx -d in.dreamate.me`. Xong khi: `curl -s https://in.dreamate.me/api/v1/health` ra UP và `https://mitritex.tino.page` (n8n) vẫn mở được.
5. **Render:** Dashboard → New → Blueprint → chọn repo `xuong-in-minh-tri` (đọc `render.yaml`) → Apply. Xong khi: trang Render mở được, không hiện "Chế độ demo".
6. Kiểm trên bản thật theo mục 5.

## 4. Các bước lùi bản
- Backend lỗi: `cd /opt/xuong-in/app/deploy && docker compose down` (chỉ container xuong-in), app cũ trên Render vẫn còn nếu chưa xoá. Lùi bản build: `git checkout <commit trước>` rồi `docker compose up -d --build`.
- Gỡ hẳn: xoá symlink `/etc/nginx/sites-enabled/in.dreamate.me`, `nginx -t && systemctl reload nginx`.
- Frontend lỗi: Render → Deploys → chọn bản trước → "Rollback".
- Không có database; dữ liệu chỉ là file tạm 48 giờ, không cần sao lưu.
